# local-voice-assistant
Разработка локального голосового ассистента для студентов лаборатории на основе локальной большой языковой модели
Голосовой ассистент лаборатории (LabVoiceAI)
Локальный голосовой ассистент на базе LLM для студентов лаборатории. Помогает новичкам быстро находить ответы на вопросы, связанные с работой лаборатории, оборудованием, методиками и правилами
